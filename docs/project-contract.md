# Shared E project contract

## Visual reference
BKC/Auzietek direction: blue-ranged metal borders, menus and bars; navy shadows, brushed blue steel and restrained ice-blue electric highlights with readable text.
Theme scene: kneeling BlackKnight, sword grounded, dark foggy mountains; glowing eyes and occasional lightning. Composition and exact pose remain exploratory.
Transient-Color's compact DR13/14/16 nod and Sci-Fi's night/lightning effect are source-study leads. Inspect actual EDC/EDJ mechanisms and provenance before selecting reused assets; E27 rendering remains to be verified.
Keep animated and low-motion options coherent. Measure idle cost and readability on laptop/external displays before accepting animation defaults.

## Project ownership
Theme kit owns desktop/background assets, theme build instructions and tutorial examples.
Media player owns its EFL presentation, application state, media engine adapter and provider adapters. Shared palette/design reference does not make the projects code dependencies.
Clementine is the requested feature/backend reference; inspect actual reusable components and Qt coupling. Rage/Emotion may be compared but are not the assumed foundation. No engine is selected yet.
Provider authentication, catalog access and audio delivery are separate. Spotify compliance is a requirement, not a label earned by using OAuth, librespot or a promotion sidebar. Credentials belong on supported provider flows; QR mode requires an established supported mechanism.

## Working method
At task start identify deliverable, owning project/component, acceptance criteria and source evidence. Before each substantial change connect it to that deliverable.
Keep instructions short and detailed research separate. Implement one demonstrated slice; record additional ideas without following them automatically.
Use existing code-native theme assets for theme mechanics. Generate raster artwork only when selected as a task. Tutorial lessons describe examples actually built and verified, with editable sources.
