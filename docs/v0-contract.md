# E-Jamz v0 contract
Local audio first: WAV, MP3, FLAC, Ogg/Vorbis candidates and tracker MOD/S3M/XM (IT optional), accepted only after representative playback tests. Playlist/queue, save/load, play/pause/stop, previous/next, volume and capability-aware seek. Unsupported/corrupt/missing files give recoverable errors without losing queue state.
Compact glossy light-blue metal, Winamp-inspired controls and optional playlist pane. Native EFL/Edje layout; no visualizer, eplet, video or theme-kit work in this slice.
Provider adapters reserve authentication, browsing, source resolution and playback capabilities. Direct URL and Spotify/FM-style services remain disabled; the user-specified fm.com service identity/API remains unverified. No credentials or network playback in v0.
Dialogs use versioned JSON definitions and an explicit action registry; no embedded scripts, imports, shell commands or arbitrary callbacks. EFL owns widgets; application code owns behaviour. Plugin metadata declares capabilities and required libraries. Missing dependencies disable the plugin with an explanation; no host package installation.
Selected backend direction: GStreamer as primary playback/processing/output owner; FFmpeg/libav supports demonstrated codec/tooling needs. Tracker decoding/plugin or libopenmpt PCM integration remains pending compile/link and playback evidence, including seek/duration behaviour. Clementine remains a feature/design reference, not imported application code.
Next runtime acceptance: mixed playlist with licensed WAV/MP3/FLAC/Ogg/MOD/S3M/XM fixtures, queue advance, persistence, errors and supported seek. Record fixture provenance and audible output separately from compilation.

The matching companion sound rack is part of the product design; DSP follows the first local-playback proof. Independent panel visibility shares one audio core. Library discovery/relinking and explicitly prompted collection organization follow usable playback; no file relocation in v0 playback work. See product-design.md and library-relocation.md.
